Week 1 · October 5, 2026 · covering September 28 – October 5, 2026

Agents shipped this week. The controls around them did not.

Always-on agents arrived while permission scoping, spend caps, and agent attribution lag behind. Plus agent-identity funding, decision models, and OpenAI shelving GPT-6.1 Astra.

This week at a glance ranked, most important first

GapsMissing pieces in real products

  1. macOS has no scoped, read-only permission for AI agents
  2. Websites can’t reliably tell which company’s agent is hitting them
  3. No default hard spending caps on usage-billed cloud services
  4. ChatGPT: moving Custom GPTs to plugins loses link sharing and consistent behavior
  5. Gemini: Skills replace Gems without Canvas, Deep Research, or sharing, and Opal workflows don’t carry over
  6. Android Auto: Gemini replaced Assistant with no reliable mode for simple commands
  7. macOS 27: no single switch to turn off Apple Intelligence, and its models stay on disk

MarketsEmerging in apps and digital products

  1. Agent identity, verification, and network controls
  2. Decision models: small models that pick from a fixed list instead of writing text
  3. Durable execution for long-running agents
  4. RL training environments for specific professions
  5. Industrial “physical AI” robotics
  6. Inference hardware built around memory limits

AIThe week's key AI updates

  1. OpenAI begins rolling out always-on agents (“dots”)
  2. OpenAI shelves GPT-6.1 Astra after safety tests and ships the cheaper GPT-6.1 Sol
  3. Google announces Gemini 4 Argon, released first to cyber defenders
  4. Oversight increases: FTC probe, California subpoena, White House accord
  5. Anthropic releases Claude Sonnet 5.5
  6. New open-weight models: Reflection Beam and Aleph Alpha Kolibri
  7. Cloudflare launches a Web Search API for agents, with verified-bot rules for providers
