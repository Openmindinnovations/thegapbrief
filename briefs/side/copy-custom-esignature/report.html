Copying Custom Esignature: How Hard, and What Bots It Takes

A team email signature manager is easy to demo and hard to ship well. The editor is a weekend's work. Getting signatures into every Gmail and Outlook mailbox, and passing Google's and Microsoft's security reviews, is the real project. The market is also crowded with cheap, established tools.

Assigned by Jacob Peterson · Research. Checked Nov 4, 2026. Prices come from each vendor's own page unless noted. Customer counts and growth claims are the vendors' own, attributed as such. Build times and difficulty ratings are [Estimate]. This report gives no market size or revenue projections.

SummaryBottom line

1Verdict: medium to build, hard to ship, hard to win

Difficulty [Estimate]: 6/10 overall. The editor, templates, hosting, a team dashboard and click analytics are routine web work, about 3–5 weeks for a bot team. The hard 40% is deployment: writing signatures into Gmail needs a restricted Google scope (yearly CASA assessment), and Microsoft has no Graph API for Outlook signatures, so you need an Outlook add-in or mail routing through your own servers.

Biggest hurdle: trust and distribution, not code. You need Google verification plus CASA, Microsoft publisher verification and admin consent, and rendering that holds up in classic Outlook. Then you're competing with CodeTwo and Exclaimer at about $1 a user per month.

Bots needed: 5 (PM, Builder, Integrations, QA/Render, Growth & Support). That's a deliberately lean team, after the usage report showed chat between bots is the main usage cost.

3The technical build, piece by piece

3.1Signature editor and templates · Difficulty 2/10 [Estimate]

A form-plus-preview editor (name, title, photo, logo, links, socials, banner) that outputs table-based HTML with inline CSS. Drag and drop is nice to have. "AI" can mean generating a layout and palette from a logo or website URL, which is one LLM call plus templates.

General practice.

3.2HTML that renders everywhere · Difficulty 6/10 [Estimate]

Classic Outlook for Windows renders with Word's engine, so you need tables, inline styles, no flexbox or grid and fixed image sizes. Animated GIFs may play only the first frame in some Outlook versions, so the first frame of an "animated logo" must look finished. Gmail removes <style> blocks in some contexts, and Gmail caps signature length, so long HTML can be rejected. Dark mode can invert colors. Hover effects (their "interactive nav bar") don't work in most clients. Plan a test matrix: Gmail web and app, Outlook classic, new Outlook, Mac, iOS Mail.

Can I email (client support tables) · Gmail Help: signatures (character limit)

3.3Gmail deployment (Google Workspace) · Difficulty 7/10 [Estimate]

The standard approach is the Gmail API users.settings.sendAs.update, which sets the signature for each user. Org-wide, an admin grants domain-wide delegation to your service account so you can write every user's signature, and directory data (names, titles) comes from the Admin SDK Directory API. The catch: the needed scope, gmail.settings.basic, is listed by Google as a restricted scope. Public apps need restricted-scope verification, and apps that store or move restricted data on servers need a third-party CASA security assessment, renewed every year. Google says unverified apps using restricted scopes are capped at 100 users.

CASA cost (sourced): Google says assessor fees run $500–$4,500 depending on complexity, and that tier-2 assessments take 2–3 weeks. TAC Security lists AL1 Basic at $675, and Secusy lists AL1 from $499 and AL2 at $5,400.

3.4Microsoft 365 / Outlook deployment · Difficulty 8/10 [Estimate]

No signature API. Microsoft Q&A answers say signatures can't be managed through Graph, and Graph's mailboxSettings has no signature field. Exclaimer adds that EWS, which some tools used to write signatures, is blocked by default from Oct 1, 2026 and shuts down fully in April 2027. Set-MailboxMessageConfiguration stops applying once roaming signatures are on. That leaves three routes:

(a) Outlook add-in with event-based activation: OnNewMessageCompose plus body.setSignatureAsync (requirement set 1.10). It works across web, new Outlook, classic Windows, Mac and mobile, but handlers get at most 60 seconds, and admins must deploy it centrally. (b) Server-side: an Exchange Online connector plus mail flow rule that routes outbound mail through your cloud, which stamps the signature on every device. This is CodeTwo's "cloud mode," and it's the heaviest to run because you're in the mail path (uptime, TLS, loops, deliverability). (c) Transport-rule disclaimer HTML: built in and free, but limited (it's appended at the bottom, under the reply chain).

Consent: a multi-tenant Entra app needs a verified publisher, and application permissions (reading the directory with User.Read.All) need tenant admin consent. Microsoft 365 App Compliance certification, which CodeTwo advertises, is optional but is what IT buyers look for.

Microsoft Q&A: signatures not in Graph · Exclaimer: Graph, EWS and roaming signatures · Microsoft Learn: event-based activation · Microsoft sample: set signature · Microsoft Learn: publisher verification

3.5"Sync anywhere" without integrations · Difficulty 2/10 [Estimate]

For solo users and other clients (Apple Mail, Yahoo, CRMs), copy-paste install guides with a "copy signature" button cover most of it, and that's what "works with any email or CRM" usually means. A Chrome extension that inserts the signature in Gmail compose is a middle option that avoids restricted scopes.

General practice.

3.6Hosting, analytics and banners · Difficulty 3/10 [Estimate]

Images and animated GIFs go on a CDN under your own domain. Click analytics come from redirect links (/c/<id>). Impressions need an image request, which is effectively a tracking pixel, and Custom Esignature says it uses no tracking pixels, so be careful what you claim. Apple Mail Privacy Protection and Gmail's image proxy also make open counts unreliable. Banners are a scheduled image plus a link per department.

Apple: Mail Privacy Protection

3.7Team dashboard, directory sync and billing · Difficulty 4/10 [Estimate]

Workspaces, roles, departments, template assignment and bulk CSV import, plus directory sync from the Google Admin SDK or Microsoft Graph users (which is fine for reading profiles). Seat-based Stripe billing. Standard SaaS work.

General practice.

6How to win instead of copying

6.1Angles worth testing [Idea, untested]

1) Price clarity for teams of 3–25: the leaders have 10-seat minimums (CodeTwo, Exclaimer), so a flat small-team price fills a real gap. 2) Vertical packs with compliance built in: real estate license numbers, legal and financial disclaimers, HIPAA-safe healthcare footers, all as template fields. 3) Honest analytics: clicks only, no pixels, stated plainly. 4) Agency mode: one dashboard for many client brands, resold white-label. 5) Outlook-first for small Microsoft shops, using the add-in route, which still avoids mail routing.

Based on the published minimums and plans in section 2.

6.2Legal and IP cautions

Don't reuse their copy, template designs, animations, screenshots, names ("AI Logo Animation™" is marked as a trademark on their site) or the "verification badge" look. Write original copy and design original templates. Don't name them in ads, and keep comparison claims factual and sourced. A "verified" badge that doesn't verify anything is a consumer-protection risk, so only use the word if you actually verify the domain. Tracking or "impression" claims need a privacy policy that matches. Follow CAN-SPAM in promotional banners, and follow Google's and Microsoft's data policies (minimal scopes, deletion on request). This isn't legal advice, so get a lawyer's review before launch.
